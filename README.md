# כפר של 100 — אתר שיעור דמוגרפיה

עזר כיתתי לשיעור דמוגרפיה (השכלה כללית). התלמידים מנחשים את ההרכב הדמוגרפי של
ישראל במודל של **כפר של 100 א.נשים**, הניחוש הכיתתי הממוצע מוצג חזותית על מסך
המורה כ-100 דמויות, ואז נחשפת **חלוקת האמת** לפי נתוני הלשכה המרכזית לסטטיסטיקה.
הפער בין הניחוש לאמת הוא רגע הלמידה.

ארבעה סבבים, לפי הסדר: **א׳ גברים ונשים · ב׳ דת · ג׳ הגדרה עצמית של דתיות ·
ד׳ סוגי יישובים**.

---

## איך זה עובד בכיתה

1. המורה פותח/ת את `teacher.html` על המקרן ולוחץ/ת "פתיחת חדר". מופיע **קוד חדר**
   (וגם QR וקישור).
2. כל תלמיד/ה פותח/ת את `index.html` בטלפון ומקליד/ה את הקוד (או סורק/ת QR).
3. המורה שולט/ת בקצב: כל הכיתה עונה על אותו סבב יחד. בכל סבב מוצגת שורת הבסיס
   ("מתוך 100 ישראלים" או "מתוך 100 יהודים בני 20 ומעלה").
4. כל תלמיד/ה מזין/ה מספר לכל קטגוריה; אפשר לשלוח רק כשהסכום **בדיוק 100**.
5. מסך המורה מציג את הממוצע הכיתתי כ-100 דמויות בזמן אמת. בלחיצה על **"חשוף אמת"**
   הדמויות עוברות באנימציה אל חלוקת האמת.
6. "הבא ▶" עובר לסבב הבא.

---

## הרצה מקומית (ללא Firebase)

פשוט פותחים את `teacher.html` ואת `index.html` בכרטיסיות נפרדות **באותו דפדפן**.
במצב הזה הסנכרון נעשה דרך הדפדפן בלבד (BroadcastChannel) — מצוין לבדיקה, אבל
**לא** עובד בין מכשירים שונים. תופיע הודעת "מצב הדגמה מקומי".

לשיעור אמיתי בכיתה חובה לחבר Firebase (למטה).

---

## הקמת Firebase (כ-5 דקות, חינמי)

1. היכנסו ל-<https://console.firebase.google.com> וצרו פרויקט חדש.
2. **יצירת מסד הנתונים:** בשורת החיפוש למעלה הקלידו `Realtime Database` (או:
   בתפריט השמאלי → **Databases & Storage** → **Realtime Database**). שימו לב —
   **Realtime Database**, לא Firestore. לחצו **Create Database**, בחרו אזור
   (למשל `europe-west1`) והתחילו ב-**test mode** (נחליף כללים בהמשך).
   > הערה: בקונסולה החדשה אין יותר תפריט "Build" — הכל מסודר לפי קטגוריות.
3. בטאב **Data** של המסד, בראש הטבלה, מופיעה כתובת כמו
   `https://<פרויקט>-default-rtdb.europe-west1.firebasedatabase.app/` — זה
   ה-`databaseURL`. העתיקו אותה.
4. בהגדרות הפרויקט (גלגל השיניים → Project settings → General), תחת
   **Your apps**, הוסיפו אפליקציית **Web** (אייקון `</>`). העתיקו את אובייקט
   `firebaseConfig`.
5. הדביקו אותו ל-`js/config.js` (שדות `apiKey` ו-`databaseURL` הם ההכרחיים).
   ודאו ש-`databaseURL` זהה לכתובת משלב 3 — לפעמים היא חסרה ב-config שנוצר
   אוטומטית וצריך להוסיף ידנית. ברגע שהשדות מלאים, האתר עובר אוטומטית לעבוד
   מול Firebase.

### כללי אבטחה מומלצים ל-Database

ברירת המחדל של test mode פתוחה לגמרי ותפוג אחרי 30 יום. לשימוש כיתתי מומלץ
להגביל לקריאה/כתיבה תחת `rooms` בלבד. ב-**Realtime Database → Rules**:

```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true,
      "$room": {
        ".validate": "$room.length <= 8"
      }
    }
  }
}
```

זהו איזון פרקטי לשיעור חד-פעמי: אין מידע אישי (התלמידים אנונימיים), והנתונים
הם מספרים בלבד. למי שרוצה הידוק נוסף אפשר להפעיל **Anonymous Auth** ולהחליף את
`.read`/`.write` ב-`"auth != null"`.

## פריסה ל-GitHub Pages

1. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, תיקייה `/`.
2. הקישור יהיה `https://<user>.github.io/Demographics-Israel/`.
   - מסך המורה: `.../teacher.html`
   - מסך התלמיד: `.../index.html`

> שימו לב: `js/config.js` עם מפתחות Firebase ייחשף באתר (הם מפתחות צד-לקוח
> ציבוריים). האבטחה מתבצעת דרך כללי ה-Database, לא דרך הסתרת המפתחות.

## עריכת הנתונים

כל התוכן (שאלות, קטגוריות, צבעים ונתוני האמת) נמצא במקום אחד: **`js/data.js`**,
במערך `QUESTIONS`. שמות הקטגוריות והסדר שלהם נלקחו מילה-במילה מנתוני הלמ"ס; כל
סבב מסתכם בדיוק ב-100.
